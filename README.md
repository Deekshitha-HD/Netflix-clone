# Netflix Clone

A simple Netflix-inspired landing page built with HTML, CSS, and JavaScript. The page features a full-screen background video, navigation bar, profile dropdown, and movie action buttons.

## Features

- Full-screen Moana background video
- Netflix-style navigation bar
- Search, speaker, and notification icons
- Profile dropdown menu
- Play and More Info buttons
- Responsive typography and layout styles

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this project.
2. Open `main.html` in a web browser.

No build tools or dependencies are required.

## Notes

- The project uses a locally hosted Moana teaser video.
- Browsers may block autoplay with sound, so the JavaScript attempts to enable sound after a user interaction.
